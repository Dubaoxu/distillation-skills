## 一、核心方法论共识 (Core Consensus)

> 穿越六个领域的底层统一范式 —— 这是所有流派都认可的"硬核"

### 共识 1：反馈是控制的灵魂

**跨域证据**：
- **鲁棒控制**：反馈压缩不确定性对输出的影响（小增益定理）
- **自适应控制**：在线反馈调整控制器参数实现自校正
- **MPC**：滚动时域反馈修正开环预测偏差
- **RL 控制**：价值函数和策略梯度都是反馈信号的形式化
- **导航**：SLAM 的回环检测就是全局反馈校正累积漂移

**核心主张**：无论用什么数学工具，控制的本质 = 观测→比较→修正→再观测的反馈循环

### 共识 2：模型的角色是从"可有可无"到"越精确越好"

**跨域证据**：
- **无模型 RL** (SAC/PPO)：完全不要模型也能控制，但样本效率低
- **基于模型 RL** (Dreamer/MBPO)：世界模型显著提升样本效率
- **MPC**：显式优化模型预测是最优控制的标准做法
- **自适应控制**：在线建模是关键（参数估计/系统辨识）
- **鲁棒控制**：不需要精确模型，但需要不确定性的界限

**核心主张**：模型不是"要不要"的问题，是"用多少"和在"什么粒度上用"的问题

### 共识 3：约束处理是实际部署的第一道门槛

**跨域证据**：
- **MPC**：天然处理输入/状态/输出约束（优化问题中直接编码）
- **安全 RL**：CPO/CBF/Lagrangian 方法——约束是安全性的形式化
- **鲁棒控制**：H∞ 将约束转化为加权混合灵敏度
- **导航**：DWA 的"动态窗口"本质是速度约束下的优化
- **导盲**：用户安全是最高优先级约束，不可妥协

**核心主张**：满足约束比优化性能更重要——一个违反约束的最优控制器等于没有控制器

### 共识 4：不确定性量化决定控制器的可靠性边界

**跨域证据**：
- **鲁棒控制**：结构化/非结构化不确定性显式建模（小增益/μ综合）
- **MPC**：Tube MPC / 随机MPC / 机会约束MPC
- **RL 控制**：领域随机化 / 分布鲁棒优化
- **自适应控制**：参数不确定性→在线参数估计

**核心主张**：承认"我不知道"比假装"我都知道"更可靠

### 共识 5：数据驱动与模型驱动在融合而非对立

**跨域证据**：
- **DeePC (2019)**：纯数据驱动MPC，基于Willems行为理论
- **Koopman MPC (2025)**：从数据学习Koopman算子→升维→线性化非线性系统
- **Offline RL + Control**：CQL/IQL 从历史数据学习安全策略
- **数据驱动 SMC (2024)**：系统文献综述，256篇参考文献
- **Sim-to-Real**：仿真数据→真实系统迁移的核心方法论

**核心主张**：数据告诉你过去发生了什么，模型告诉你为什么会发生——两者结合才能预测未来

### 共识 6：实时性是不可妥协的硬约束

**跨域证据**：
- **显式 MPC (Bemporad, 2002)**：将在线优化离线化→在线=查表
- **RTI (Diehl, 2002)**：NMPC实时迭代，牺牲最优性换速度
- **事件触发控制**：只在必要时计算控制，节省通信/计算
- **SLAM**：PTAM (2007) 的并行跟踪+建图架构定义了实时SLAM范式
- **SMC**：滑模控制天然适合实时（简单的切换律）

**核心主张**：再好的控制器如果不能实时执行就没有意义

### 共识 7：层次化架构是大系统的必然选择

**跨域证据**：
- **MPC**：上层规划+下层跟踪（如路径规划→MPC跟踪）
- **RL + 传统控制**：RL做高层决策，PID/MPC做低层控制
- **导航**：全局A*/RRT+局部DWA/TEB
- **分布式 MPC**：子系统独立MPC+协调层

**核心主张**：分而治之——把复杂问题分解为不同时间尺度的子问题

## 二、学派分歧与演进路线 (Key Divergences)

### 分歧 1：模型精度 vs 鲁棒性 —— 古老的两难

| 阵营 | 立场 | 代表方法 |
|------|------|---------|
| **模型精度派** | 模型越精确控制越好，值得投入计算获取精确模型 | NMPC、Gaussian Process MPC、Dreamer |
| **鲁棒优先派** | 模型总有误差，不如直接设计对误差不敏感的控制器 | H∞、SMC、Tube MPC |
| **折中派（2020s 主流）** | 学习可用的模型 + 鲁棒的约束处理 | Learning-based MPC + Safety Filter |

### 分歧 2：在线优化 vs 离线训练

| 阵营 | 立场 | 代表方法 |
|------|------|---------|
| **在线优化** | 每步重解优化问题，对变化场景适应性强 | MPC、NMPC、Tube MPC |
| **离线训练** | 提前训练好策略/控制器，在线只需前向推理 | RL (PPO/SAC)、显式MPC、ILC |
| **融合趋势（2025 最热）** | 离线训练策略 + 在线MPC安全监督 | RL+MPC融合三类架构 |

### 分歧 3：控制理论与机器学习的方法论之争

| 传统控制 | 机器学习 |
|---------|---------|
| **稳定性证明优先** | 经验性性能优先 |
| **数学保证** (Lyapunov/不变集/ISS) | **统计保证** (PAC/regret) |
| **模型=物理方程** | **模型=神经网络** |
| **代表**：鲁棒/自适应/H∞/MPC稳定理论 | **代表**：DRL/端到端学习/模仿学习 |

**2025 融合趋势**：
- CBF + RL：控制理论给出安全证书，RL提升性能
- Koopman 算子：用数据学习方法将非线性系统映射为线性（可证明）
- DeePC：行为理论的纯数据驱动MPC（数学保证+数据驱动）

### 分歧 4：自适应机制的实现路径

| 路径 | 方案 | 优势 | 局限 |
|------|------|------|------|
| **参数自适应** | MRAC/STR/反步法 | 理论完备，稳定证明丰富 | 需要参数化结构假设 |
| **函数逼近自适应** | 神经网络自适应/RKHS MRAC | 不需要参数化假设 | 计算代价高，稳定性难证明 |
| **学习自适应** | RL + System ID | 灵活通用 | 样本效率低 |
| **L1自适应** | Cao/Hovakimyan | 快速自适应+确保鲁棒性 | 高增益可能放大噪声 |

### 分歧 5：SLAM 范式之争（从滤波到优化）

| 范式 | 代表 | 时代 | 核心思想 |
|------|------|------|---------|
| **滤波 SLAM** | EKF-SLAM → FastSLAM | 1990s–2000s | 贝叶斯滤波/粒子滤波 |
| **关键帧 BA SLAM** | PTAM → ORB-SLAM | 2007–现在 | 稀疏非线性优化(Bundle Adjustment) |
| **直接法 SLAM** | LSD-SLAM → DSO | 2014–现在 | 直接优化光度误差 |
| **学习 SLAM** | NeRF-SLAM/3DGS-SLAM | 2022–现在 | 神经隐式表示替代传统地图 |

### 分歧 6：辅助导航的技术路线分化

| 方案 | 优势 | 局限 |
|------|------|------|
| **纯CV (智能手机)** | 成本低、普及快 | 光照/角度敏感 |
| **专用硬件 (智能眼镜/背心)** | 传感器品质高、专为盲人设计 | 成本高 (NOA ~$2000+) |
| **基础设施依赖 (BLE/UWB)** | 室内精度高 | 需要提前部署 |
| **导盲机器人** | 功能最全面 | 体积大、社会接受度待验证 |

## 三、五层技术栈模型

```
┌──────────────────────────────────────────────────────┐
│ 第 5 层：决策规划层                                    │
│ 路径规划 (A*/RRT) · 任务规划 · RL 高层策略               │
│ 代表：全局导航、MPC 滚动优化、强化学习                    │
├──────────────────────────────────────────────────────┤
│ 第 4 层：约束安全层                                    │
│ CBF · CPO · Safety Filter · 鲁棒不变量集                │
│ 代表：安全 RL、Tube MPC、导盲安全验证                    │
├──────────────────────────────────────────────────────┤
│ 第 3 层：控制合成层                                    │
│ H∞ · SMC · MRAC · MPC · PPO/SAC                      │
│ 代表：鲁棒/自适应/最优/学习控制器                        │
├──────────────────────────────────────────────────────┤
│ 第 2 层：感知估计层                                    │
│ SLAM · 传感器融合 (EKF/UKF/PF) · 状态观测器              │
│ 代表：定位、建图、目标检测、深度估计                      │
├──────────────────────────────────────────────────────┤
│ 第 1 层：物理建模层                                    │
│ 运动学/动力学 · Koopman 算子 · 系统辨识                  │
│ 代表：机器人/车辆/飞行器数学模型                          │
└──────────────────────────────────────────────────────┘
```

**层间依赖关系**：
- 第 1 层决定第 2 层的状态空间维度和可观测性
- 第 2 层提供第 3 层的反馈信号（状态估计+不确定性）
- 第 3 层的输出必须经过第 4 层的安全检查
- 第 4 层的安全约束是第 5 层规划的可行域边界

## 五、诚实边界 (Honest Boundaries)

此框架基于 2026 年 5 月的文献调研，存在以下局限：

1. **调研范围**：覆盖 6 个领域，但每个领域内的子方向不可能穷尽。例如自适应控制中的多模型自适应、模糊自适应等只做了代表性覆盖
2. **时间截止**：2025 年以后的最新 preprint 可能未被充分纳入
3. **深度优先 vs 广度优先**：本次侧重广度覆盖以建立跨域联系，每个子领域的深度论文需要查阅各调研文件的完整列表
4. **RL 领域**：RL 发展极快（每月数百篇 arXiv 论文），本调研仅覆盖控制相关的 RL 论文
5. **导盲领域**：以综述和系统级论文为主，底层传感器硬件论文未深入覆盖
6. **中文文献**：本次以英文学术论文为主，中文学术期刊论文（自动化学报、控制理论与应用等）覆盖不足
7. **专利和商业产品**：未纳入专利文献和商业产品技术方案
8. **数学理论深度**：底层控制数学理论（如 ISS、无源理论、耗散系统等）的讨论以引用为主，未做章节级展开
